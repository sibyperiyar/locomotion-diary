# Installation & Updates ⬇️

## How to Install

Locomotion Diary is a **Progressive Web App (PWA)**. You don't need an app store!

### Desktop (Chrome/Edge)

1. Open the app in your browser.
2. Look for the **Install** icon (usually a computer with a down arrow) in the address bar.
3. Click **Install**. The app will now launch in its own window and work offline.

### Mobile (Android/iOS)

1. Open the app in Chrome (Android) or Safari (iOS).
2. Tap the browser menu (three dots or share icon).
3. Select **"Add to Home Screen"**.

## How to Update 🔄

When a new version is released:

1. Go to **Settings ⚙️**.
2. Click **Check for Updates** (if a server is configured) or simply download the latest ZIP from GitHub.
3. **Replace** the files in your installation folder.
4. Reload the page.
5. *Optional:* Go to **Settings > Force Reload App** to ensure all new features are loaded.
