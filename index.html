How to get your data

  1. Go to Google Takeout.
  2. Deselect all, then select only Location History (Timeline).
  3. Click Next Step and choose "Export once".
  4. Download the ZIP file and extract it.
  5. Look for a file named Records.json (or year files like 2024_JANUARY.json).
  6. Drag that file into this app!
